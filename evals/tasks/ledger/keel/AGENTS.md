# ledger — AGENTS.md

ledger is a command-line tool that splits shared expenses in a small group (Node.js 20+, standard library only, one JSON file). Exact-to-the-cent money ranks above convenience.

This file is deliberately light. The documents below are the source of truth. When this file and a referenced doc disagree, the doc wins.

## Hard invariants (rationale: ARCHITECTURE §1, §4)

| # | Rule | Enforced by | Gap | Source |
|---|---|---|---|---|
| 1 | Money is integer cents; never `parseFloat`/float math on amounts | `tests/money.test.js` sum-to-amount sweep | Not built until Phase 1 | ADR-001 |
| 2 | Standard library only: imports are `node:`-prefixed or relative; no npm deps | `tests/no-deps.test.js` | Not built until Phase 0 | BRD CON-001 |
| 3 | Shares sum exactly to the amount; leftover cents go one each, alphabetically | `tests/money.test.js` | Not built until Phase 1 | ARCHITECTURE §4 |
| 4 | Invalid input → `error:` on stderr, exit 2, no file change; only `cli.js` prints/exits | `tests/cli.test.js` | Not built until Phase 0/2 | ADR-003 |
| 5 | Expense ids are never reused (`nextId` persisted, never lowered) | `tests/cli.test.js` | Not built until Phase 2 | ADR-002 |
| 6 | Writes are atomic (temp file + rename); a bad data file is never overwritten | `tests/store.test.js` | Not built until Phase 2 | ADR-002 |

## Git & working workflow (mandatory — the build loop)

0. **Git from commit one:** commit the generated docs on `main` before any feature work.
1. **Two units of work:** a Phase on `phase-N-<slug>`; a Change on `chg/<slug>` (`/keel change <slug>`). Never commit to `main` after the docs commit.
2. **Run the phase script:** `claude --workflow .claude/workflows/phase-N-<slug>.js` (mechanics: `.claude/workflows/README.md`).
3. **Tests ship with the code** (`node:test`); each BRD behaviour is pinned by a test.
4. **Done per change:** `node --test` green, size + link check passes (`node .keel/doc-size.mjs`), invariants above hold.
5. **Doc sync before the completing commit:** inline when only status lines change, else delegate to doc-sync (`.claude/agents/doc-sync.md`; `doc-sync.js`, ≤3 rounds, then deferred items).
6. **Merge** only with gates green and the doc-sync commit present. There is no deploy; `[merged]` is the final state.
7. **Decisions → `docs/adr/` before merge** (no addenda; open questions in `docs/adr/README.md`).
8. **Claims carry evidence:** no `✅` without a level (`code-read` < `unit` < `integration`) and an artefact.

Rules and rationale: IMPLEMENTATION_PLAN "Standing rules". Delegation: `.claude/workflows/README.md`.

## Stops and end-of-run report

**Stop and ask** before: adding any dependency or `package.json` dependency; changing a spec line in `prompt.md`/BRD; deleting or rewriting a user's `ledger.json`; or when two docs disagree on something the task depends on.
**End every run with four lines:** Blocked on me · Changed · Found · Could not confirm.

## Pre-PR checklist

- [ ] (1) no float arithmetic or `parseFloat` on amounts
- [ ] (2) no import outside `node:` and relative paths; no dependencies added
- [ ] (3) shares sum to the amount in every split path
- [ ] (4) every new error path throws `CliError`/`DataError`; nothing else exits
- [ ] (5) ids come from `nextId`; `remove` does not lower it
- [ ] (6) saves go through the atomic writer
